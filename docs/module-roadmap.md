# Module roadmap

1. Project foundation and multi-tenancy (implemented).
2. Authentication, school memberships, RBAC, and API security (implemented; awaiting user review).
3. School profile and configuration.
4. Academic structure — sessions, terms, classes, subjects, and grading configuration.
5. Student management and enrollment.
6. Staff and teacher management.
7. Attendance management.
8. Results entry, calculation, and approval.
9. Report-card generation, finalization, versions, PDF output, and free reprints.
10. Credit packages, balances, usage ledger, and credit deduction rules.
11. Payment integration and secure webhook processing.
12. Platform administration, audit logging, security hardening, and production preparation.

Later modules may adjust this order or detail in response to real school requirements. Do not begin Module 3 until Module 2 is reviewed and approved.
